# 极简图片打码工具 — 需求规范

## 一、项目概述

本项目是一款**轻量级本地图片打码工具**，无需网络，双击即可在电脑上运行。
用户通过鼠标拖拽在图片上框选任意区域，松开即对选区应用打码效果，并可保存处理后的图片。

- **项目入口**：`mosaic_tool.py`（项目根目录）
- **技术栈**：Python 3.12 + PyQt6（窗口与交互）+ Pillow（图像处理）

---

## 二、功能需求

### 2.1 核心功能

| 编号 | 功能 | 需求描述 |
|---|---|---|
| F1 | 打开图片 | 支持 PNG / JPG / JPEG / BMP；打开失败时弹窗提示 |
| F2 | 拖拽框选 | 按住鼠标左键拖拽，实时显示红色虚线选框；仅允许从图片区域内开始框选；支持反向拖拽（自动归一化） |
| F3 | 松开打码 | 松开左键即对选区应用打码，并自动清除选框 |
| F4 | 清除选区 | 按钮清除当前未完成的拖拽状态 |
| F5 | 保存图片 | 支持 **PNG / JPEG / BMP / WEBP / TIFF** 五种格式；未输入扩展名时按所选格式自动补全；JPEG 以 quality=95 保存 |

### 2.2 进阶功能

| 编号 | 功能 | 需求描述 |
|---|---|---|
| F6 | 打码方式切换 | 下拉框切换「马赛克 / 高斯模糊」两种方式 |
| F7 | 强度调节 | 滑块范围 4–30，默认 10；同时控制马赛克格子粗细与高斯模糊半径 |
| F8 | 撤销 | 每次打码前保存历史状态，可逐步撤销；撤销栈上限 20 步 |

### 2.3 显示质量要求

| 编号 | 需求 | 描述 |
|---|---|---|
| Q1 | 高质量缩放 | 显示缩放使用 Pillow LANCZOS 重采样，画质优于 Qt 自带缩放 |
| Q2 | 高 DPI 适配 | 按屏幕 devicePixelRatio 输出物理像素尺寸的显示图，高分屏下不发虚 |
| Q3 | 窗口自适应 | 窗口缩放时图片按比例重排并居中显示，坐标映射保持准确 |

## 三、核心实现逻辑

### 3.1 坐标映射（核心难点）

图片为适应窗口会缩放显示，鼠标拖拽得到的是**界面坐标**，需反向映射回**原图像素坐标**：

```
原图坐标 = (界面坐标 − 显示图在控件内的居中偏移) × (原图宽 / 显示图宽)
```

映射结果 clamp 到图像范围内；选区宽或高 < 2 像素时视为无效，不触发打码。

### 3.2 马赛克算法（Pillow）

1. 裁剪选区 `crop((x1, y1, x2, y2))`
2. 极度缩小至 `宽/强度`（`BILINEAR`），压缩像素信息
3. 用最近邻插值（`NEAREST`）放大回原尺寸，形成马赛克色块
4. 贴回原图 `paste` 并刷新显示

### 3.3 高斯模糊

`crop` 选区后应用 `ImageFilter.GaussianBlur(radius=强度)`，再贴回原图。

### 3.4 撤销栈

每次打码前将当前图像 `copy()` 压入栈（上限 20 步，超出丢弃最旧）；
撤销时弹出栈顶恢复图像并刷新显示。

## 四、界面布局

- **顶部工具区**：打开图片、保存图片、清除选区、撤销 | 方式下拉框、强度滑块
- **中央区域**：图片显示控件（`ImageLabel`），灰色背景、图片居中、红色虚线选框
- **窗口**：默认 800×600，可自由缩放

## 五、项目结构

## 六、运行方式

```bash
# 安装依赖
venv/Scripts/pip install -r requirements.txt

# 启动
venv/Scripts/python.exe mosaic_tool.py
```
