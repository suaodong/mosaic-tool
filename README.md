# 极简图片打码工具 — 需求规范

## 一、项目概述

本项目是一款**轻量级本地图片/PDF 打码工具**，无需网络，双击即可在电脑上运行。
用户通过鼠标拖拽在页面上框选任意区域，松开即对选区应用打码效果，并可将处理结果导出为多种格式。

- **项目入口**：`mosaic_tool.py`（项目根目录）
- **技术栈**：Python 3.12 + PyQt6（窗口与交互）+ Pillow（图像处理）+ pypdfium2（PDF 渲染）
- **独立分发**：可用 PyInstaller 打包为单文件 exe（`pyinstaller -F -w mosaic_tool.py`）

## 二、功能需求

### 2.1 核心功能

| 编号 | 功能 | 需求描述 |
|---|---|---|
| F1 | 打开文件 | 支持图片（PNG / JPG / JPEG / BMP）和 **PDF**；打开失败时弹窗提示 |
| F2 | PDF 多页支持 | PDF 按 200 DPI 逐页渲染为图片，**保留全部页面**；多页时显示「上一页 / 下一页」导航与页码 |
| F3 | 拖拽框选 | 按住鼠标左键拖拽，实时显示红色虚线选框；仅允许从页面区域内开始框选；支持反向拖拽（自动归一化） |
| F4 | 松开打码 | 松开左键即对当前页选区应用打码，并自动清除选框 |
| F5 | 清除选区 | 按钮清除当前未完成的拖拽状态 |
| F6 | 保存 / 导出 | **保存按钮下拉直接选择格式**：PNG / JPEG / BMP / WEBP / TIFF / **PDF**；未输入扩展名时按所选格式自动补全；JPEG 以 quality=95 保存 |

### 2.2 导出规则

| 规则 | 描述 |
|---|---|
| PDF 导出 | 将**全部页面重新组装**为多页 PDF（打码页替换原页），页数不丢失，页面分辨率 200 DPI |
| 图片格式导出 | 多页文档导出为图片格式时**仅导出当前页**，保存成功提示中注明 |

### 2.3 进阶功能

| 编号 | 功能 | 需求描述 |
|---|---|---|
| F7 | 打码方式切换 | 下拉框切换「马赛克 / 高斯模糊」两种方式 |
| F8 | 强度调节 | 滑块范围 4–30，默认 10；同时控制马赛克格子粗细与高斯模糊半径 |
| F9 | 撤销 | 每次打码前保存该页历史状态，可逐步撤销（自动跳回被打码页）；撤销栈上限 20 步 |

### 2.4 显示质量要求

| 编号 | 需求 | 描述 |
|---|---|---|
| Q1 | 高质量缩放 | 显示缩放使用 Pillow LANCZOS 重采样，画质优于 Qt 自带缩放 |
| Q2 | 高 DPI 适配 | 按屏幕 devicePixelRatio 输出物理像素尺寸的显示图，高分屏下不发虚 |
| Q3 | 窗口自适应 | 窗口缩放时页面按比例重排并居中显示，坐标映射保持准确 |

## 三、核心实现逻辑

### 3.1 坐标映射（核心难点）

页面为适应窗口会缩放显示，鼠标拖拽得到的是**界面坐标**，需反向映射回**原图像素坐标**：

```
原图坐标 = (界面坐标 − 显示图在控件内的居中偏移) × (原图宽 / 显示图宽)
```

映射结果 clamp 到图像范围内；选区宽或高 < 2 像素时视为无效，不触发打码。

### 3.2 PDF 渲染与重组

- **加载**：pypdfium2 以 200 DPI 将每页渲染为 PIL RGB 图片，存入页面列表
- **导出**：Pillow 多页 PDF 保存（`save_all=True, append_images=其余页, resolution=200`）

### 3.3 马赛克算法（Pillow）

1. 裁剪选区 `crop((x1, y1, x2, y2))`
2. 极度缩小至 `宽/强度`（`BILINEAR`），压缩像素信息
3. 用最近邻插值（`NEAREST`）放大回原尺寸，形成马赛克色块
4. 贴回原图 `paste` 并刷新显示

### 3.4 高斯模糊

`crop` 选区后应用 `ImageFilter.GaussianBlur(radius=强度)`，再贴回原图。

### 3.5 撤销栈

每次打码前将 `(页码, 该页副本)` 压入栈（上限 20 步，超出丢弃最旧）；
撤销时弹出栈顶，恢复对应页并跳转到该页显示。

## 四、界面布局

- **顶部工具区**：打开文件、保存 / 导出（下拉菜单）、清除选区、撤销 | 方式下拉框、强度滑块 | 翻页导航（仅多页 PDF 显示）
- **中央区域**：页面显示控件（`ImageLabel`），灰色背景、页面居中、红色虚线选框
- **窗口**：默认 800×600，可自由缩放

## 五、项目结构

## 六、运行方式

```bash
# 安装依赖
venv/Scripts/pip install -r requirements.txt

# 启动
venv/Scripts/python.exe mosaic_tool.py

# 打包为单文件 exe（产物在 dist/）
venv/Scripts/python.exe -m PyInstaller -F -w mosaic_tool.py
```
